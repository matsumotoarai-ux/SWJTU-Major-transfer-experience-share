# 西南交通大学转信息科学与技术学院经验分享
# 1.前期准备
信息学院的转专业成绩分为三个部分：15%的全部成绩平均分，20%准入成绩平均分，15%的c语言笔试（注意不是c++，与计算机程序设计基础学的不一样！）,50%的面试（很重要，建议多准备项目+竞赛）。
其中准入为大一所学的三门数学，高等数学1，高等数学2，线性代数B，题主所转入的信息安全非常看重这个，其他信息学院的专业也是，建议想转入信息学院的这三门至少至少都要达到90以上，不然会非常吃亏。
全部成绩平均分其实并没有那么重要，这个看专业，像电子科学与技术基本只要TOP1（每个专业的第一），意味着全部成绩均分也要拉满了才可以转入电子。

# 2.c语言笔试经验分享
题主建议直接开刷头歌上面的题，加入西南交通大学计算机程序设计那个课就可以直接开刷，我大一升大二这个暑假刷了160多道题，不仅笔试遇到了原题，也为转入后的c语言课程学习减轻了负担。
26的转专业考试原题我已经放在了仓库里，考的和头歌上的题一个思路，也就是重排求差和报数游戏，只不过我们考的原题是四位数字重排求差和随机数的报数游戏，还是加大了难度的。
重点是指针和链表，指针考的非常非常深，经典的有这么几个考点：*p++,*++p,*(p++),*(++p),数组的行指针与列指针，链表的插入，删除，建立：头插法与尾插法（只会考单链表，不用担心会考双向链表什么的）。
可以开通chatgpt,claude,gemini(最便宜)几个ai，将你前一天所做的题纠错并分析弱点，这几个ai对我的备考帮助很大。
