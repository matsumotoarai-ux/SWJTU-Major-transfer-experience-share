# 西南交通大学转入信息科学与技术学院｜经验分享

> 以我转入信息安全专业的经历为例，分享前期准备、C 语言笔试和面试的备考体会。

## 一、前期准备

信息学院的转专业考核成绩由四部分组成：

| 考核项目 | 占比 | 备考重点 |
| :--- | ---: | :--- |
| 全部成绩平均分 | 15% | 结合目标专业的要求安排精力 |
| 准入成绩平均分 | 20% | 重点关注三门数学课程 |
| C 语言笔试 | 15% | 多刷题，重点练习指针与链表 |
| 面试 | 50% | 提前整理项目和竞赛经历 |

准入成绩涉及大一所学的三门数学：**高等数学 1、高等数学 2、线性代数 B**。我转入的信息安全专业非常看重这部分，信息学院的其他专业也重视这三门课。建议想转入信息学院的同学尽量把三门课都考到 **90 分以上**，否则会比较吃亏。

全部成绩平均分的重要性因目标专业而异。例如，电子科学与技术专业基本只要各专业的 **TOP 1**（专业第一），因此想转入电子科学与技术，整体均分也需要尽量拉满。

## 二、C 语言笔试经验

**刷题建议。** 我建议直接加入头歌上的「西南交通大学计算机程序设计」课程刷题。我在大一升大二的暑假刷了 **160 多道题**，不仅在笔试中遇到了原题，也减轻了转入后学习 C 语言课程的负担。笔试考的是 C 语言，不是 C++，与《计算机程序设计基础》所学内容并不完全一样。

**真题思路。** 我已经把 26 年转专业考试的原题放在仓库里。考试题和头歌题的思路相近，涉及「重排求差」和「报数游戏」；我们考的是四位数字重排求差和随机数报数游戏，难度有所增加。

**重点考点。** 指针考得很深，建议重点掌握：

- 指针表达式：`*p++`、`*++p`、`*(p++)`、`*(++p)`
- 数组的行指针与列指针
- 单链表的建立（头插法、尾插法）、插入与删除

按我参加的笔试来看，链表部分只考了单链表，没有涉及双向链表。

**错题复盘。** 可以借助 ChatGPT、Claude、Gemini（我使用时最便宜）等 AI 工具，为前一天做过的题纠错、分析薄弱点。这几个工具对我的备考帮助很大。

## 三、面试准备与问题

我准备的经历和材料包括：

- 1 个 SRTP 项目
- 1 个信息学院竞赛三等奖
- 英语四级 600+、六级 500+
- 2 个信息学院相关项目

这些准备在我的面试中基本够用，老师也没有特别「拷打」我。面试时，老师问了以下问题：

1. **信息安全就业没有想象中那么好，怎么办？**  
   我的回答：仪器（我的原专业）和信息安全都需要升学，才能获得比较好的就业机会。

2. **你了解过信息安全的就业吗？**  
   我的回答：没有了解过（笑）。

3. **为什么想转入信息安全专业？**  
   我的回答：我的偶像是艾伦·图灵。他是密码学的先驱，曾在二战中破译德军的恩尼格玛机，我非常崇拜他。

4. **大一做了这么多项目，为什么没有做密码学相关的内容？**  
   我的回答：没有时间（笑）。

5. **你了解信息安全这个专业吗？**  
   我的回答：有了解过。信息安全研究的是，系统在受到攻击、存在漏洞时，如何依然得到可信保护。
